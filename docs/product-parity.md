# 产品能力对齐

React Native 和 Flutter 都是 Baby App 的正式版本。产品改动只影响一个实现或两个实现未同时交付时，应更新此表。

| 能力 | React Native | Flutter | 说明 |
| --- | --- | --- | --- |
| 宝宝资料 | 已支持 | 已支持 | 本地资料和月龄显示 |
| 统一成长时间轴 | 已支持 | 已支持 | 瞬间、成长、日常活动和里程碑 |
| 新增与编辑记录 | 已支持 | 已支持 | 包含记录详情流程 |
| 删除记录 | 已支持 | 待验证 | Flutter 行为需在真机冒烟测试中确认 |
| 私有媒体存储 | 已支持 | 已支持 | 照片和视频保存在应用私有目录 |
| 备份与恢复 | 已支持 | 待验证 | RN 已记录强化的 ZIP 备份与恢复语义；Flutter 仍需按统一产品约定验证 |

“待验证”表示实现中可能已有相关代码，但尚未依据共同产品约定完成确认，并不等同于不支持。
