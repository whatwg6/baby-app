# Baby Growth Timeline — Flutter

这是 Baby App 的 Flutter 实现，与 React Native 版本并行长期维护，应用数据保存在设备本地。

## 准备环境

所有命令都从 Flutter 应用目录运行：

```bash
cd apps/flutter
flutter pub get --enforce-lockfile
```

## 验证

```bash
flutter analyze
flutter test
```

## 运行

```bash
flutter run
```

产品能力对齐情况和有意差异记录在 [`../../docs/product-parity.md`](../../docs/product-parity.md)。
